# Enterprise AI Field Guide

A practical guide to designing, building, and operating AI in the enterprise.

AI discussions tend to spend a lot of time on models. Getting a useful service into production also requires attention to infrastructure, data, identity, security, cost, recovery, and the people responsible for keeping it running.

This field guide examines those responsibilities together. It draws on my experience across systems engineering, enterprise consulting, cloud migrations, platform engineering, SRE, and FinOps. The goal is to help practitioners make informed decisions and build systems their organizations can support.

## Who This Is For

Engineers, architects, technology leaders, and anyone responsible for bringing AI into an enterprise environment. You do not need to be a data scientist, but familiarity with applications and infrastructure will help.
